# Demos
**Date:** 2026-09-08

**Keywords:** 
Demos, Public Speaking, Synthesizing Information, Software Development

Demonstrations are key parts of both academic and professional life. This note collection explores
what a good demonstration looks like.

## What to Do
- Simplify the complexities so that they are understandable.
- It should work, if it doesn't throw it away and remake it until it works.

In the words of Dr. Thiruvathukal:
> "In order to build something meaningful even with AI; You need to know what it does."

Knowing how something works gives it meaning and purpose. A program with a lack of purpose
is directionless, and has no true meaning. Naturally, a good developer knows how their program
works; where issues occur; and documents their program. All of these things give a project meaning.
